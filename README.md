Log was born as a programming language for when you need power 
with zero restrictions and full personal responsibility—following a DIY philosophy and the question: "Why not do it the way I want?"

Log is not limited to basic applications or games. With its 5 variants, it can cover various parameters:

Log- /.log- > Designed for low-level programming with zero tolerance for errors

Log+ /.log+ > Designed to uphold the philosophy of Log while remaining capable of performing high-level processes. It might remind you of a programming language—or perhaps several.

Log++ /.log++ > In this case, "++" does not signify greater power or seriousness—at least not in the way you might imagine. 
    It is designed for controlling electronic circuits and components, and is intended to run on microcontrollers or computers with accessible GPIO pins.

Log+- /.log+- > Do you need to connect the low-level control to the high-level control? Perhaps this variant might interest you. 
      DISCLAIMER: Since the goal was to combine two functions into a single file, please be aware of the potential implications—such as increased complexity and the risk of errors. Proceed with caution.

LogAll /.logall > You know what it means. Frankenstein's favorite language.

**How can I program in Log?**

Option 1: Install compiler to run in any desktop and terminal  environment 

* Go to "Releases" - Choose and download your prefered version depending on your computer environment.

  *Windows*
* Step 1: Rename logl-windows.exe as logl.exe
* Step 2: Make the folder C:\Logl and get it inside it
* Step 3: Press Windows and type "environment variables" and open Edit the system environment variables → Environment variables.
* Step 4: On Path (user) press Edit - New and type C:\Logl - Accept everything
* Step 5: Open a terminal and type logl: It should open the REPL
* Step 6: If SmartScreen warns about "unknow editor" press more info and run anyways.

  *Linux*
* `chmod +x logl-linux
sudo mv logl-linux /usr/local/bin/logl
logl test.log+`

*MacOS*
* `chmod +x logl-macos
xattr -d com.apple.quarantine logl-macos
sudo mkdir -p /usr/local/bin
sudo mv logl-macos /usr/local/bin/logl
logl test.log+`
